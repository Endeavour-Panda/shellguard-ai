# 第三轮转换数据

由 `python -m training.build_conversion_data` 确定性生成。197 条训练、18 条验证、32 条保留测试；校验三者没有相同请求。原有 8 条验证请求不加入训练。SHA-256 记录在 manifest.json。

新增样本使用手工指定的模板和目标命令，覆盖 Bash、PowerShell、CMD 六个方向，重点包括文本读取、复制、移动、创建目录、输出文本、列目录和当前目录。原来的解释和风险训练样本保留。包含带空格的文件名，三个集合使用不同的名字。

这是**同类命令内的合成数据划分**，不是独立采集的真实用户命令集，也不是按语法家族隔离的测试。它只能测量有限场景下的格式输出和参数泛化，不能证明复杂管道、脚本、通配符、二进制文件或不同系统版本等价。读文件的编码、列目录的隐藏项、复制的覆盖交互等差异仍需人工检查。

训练期间只用 validation 选 checkpoint，不用 test 选模型超参数。测试采用严格命令字符串匹配，语义近似但写法不同也算不匹配；不擅自将模型成绩替换成规则引擎成绩。模型原始输出与应用内规则修正后的指标分列展示，并保留原始 JSON。
